# Практическая работа №7 — вариант 1

## Запуск

Нужен JDK 17 или новее. Исходный пакет ru.edu.pr04 сохранён. Откройте целиком папку распакованного архива в VS Code. Исходники уже лежат в starter_project/src; ничего переносить не нужно.

Из папки архива:

```bash
cd starter_project
bash run_selfcheck.sh
bash run.sh
```

Если терминал уже находится в starter_project, выполняйте только две команды bash. На Windows запускайте run_selfcheck.bat и run.bat. Единственный каталог сборки — starter_project/out. Его нет в архиве: он появится при компиляции. Для GitHub он исключён через .gitignore.

## Пояснения по заданию

Проверка входа: Конструкторы защищают данные. При объединении 6+5 ошибка возникает до изменения списка.

Разбор ошибочного фрагмента: Возврат внутреннего items допускает изменение подтверждённого заказа. Используются List.copyOf и неизменяемый OrderItem; increase возвращает новый объект.

Ключевое правило и локальное изменение: Изменение лимита затрагивает MAX_QUANTITY. Order защищает состояние, OrderService создаёт объекты и ведёт каталог.

Activity-диаграмма соответствует действиям и проверкам модели. В практике 7 дополнительно показан общий сценарий создания, ввода позиций, расчёта и подтверждения. class_partial содержит все существенные классы. Файлы сохранили исходные названия partial, но незавершённых блоков в них нет.
