# Практическая работа №5 — вариант 1

## Запуск

Нужен JDK 17 или новее. Исходный пакет ru.edu.pr02 сохранён. Откройте целиком папку распакованного архива в VS Code. Исходники уже лежат в starter_project/src; ничего переносить не нужно.

Из папки архива:

```bash
cd starter_project
bash run_selfcheck.sh
bash run.sh
```

Если терминал уже находится в starter_project, выполняйте только две команды bash. На Windows запускайте run_selfcheck.bat и run.bat. Единственный каталог сборки — starter_project/out. Его нет в архиве: он появится при компиляции. Для GitHub он исключён через .gitignore.

## Индивидуальная часть

Норма дня 10, переработка при hour > 10. Недельная норма остаётся 40, диапазон 0–16.

## Пример ввода

```text
8;9;10;11;12
Ожидается: сумма 50, среднее 10.00, дней переработки 2, недельная переработка 10.
```

## Пояснения по заданию

Проверка входа: parseHours сохраняет пустые поля split(";", -1) и указывает ошибочную позицию.

Разбор ошибочного фрагмента: Цикл i <= hours.length обращается к индексу за пределами массива; нужно i < hours.length.

Ключевое правило и локальное изменение: Изменение дневной нормы затрагивает DAILY_NORM в TimesheetAnalyzer.

Activity-диаграмма соответствует действиям и проверкам модели. В практике 7 дополнительно показан общий сценарий создания, ввода позиций, расчёта и подтверждения. class_partial содержит все существенные классы. Файлы сохранили исходные названия partial, но незавершённых блоков в них нет.
